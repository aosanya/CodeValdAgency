**CodeValdAgency** is the top-level organizing unit of the CodeVald platform. An Agency is a purpose-driven entity with a Mission, a Vision, structured Goals, and Workflows made up of ordered Work Items — each with a RACI role assignment. It progresses through a `Draft → Active → Achieved` lifecycle and, on creation, automatically triggers the provisioning of a Git repository and task management structure across the platform.

Part of the **CodeVald** platform — the structural layer that turns AI agent execution into accountable, goal-oriented work.
