## How to add a session

1. Copy [coding-sessions/_template.md](coding-sessions/_template.md) to a new
   file named `YYYY-MM-DD-<task-id>.md` in [coding-sessions/](coding-sessions/).
2. Fill in branch, focus, objectives, changes, tests, files modified, next steps.
3. Keep it under ~300 lines — split or trim if it grows past that.
4. Add a row to the **Index** above.
