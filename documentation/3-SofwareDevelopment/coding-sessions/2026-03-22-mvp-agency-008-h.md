## Session — 2026-03-22 (MVP-AGENCY-008-H)
**Branch**: `feature/SHAREDLIB-011_relationship-definition`
**Focus**: Type-specific URL parameters in schema-driven route generation

### Objectives
- [x] Replace the generic `{entityId}` placeholder with per-type URL params (e.g. `{workflowId}`, `{goalId}`) throughout all schema-generated HTTP route patterns
- [x] Make `EntityIDParam` compulsory — types without it only receive collection-level routes

### Changes Made

#### CodeValdSharedLib

**`types/schema.go`** — added `EntityIDParam string` to `TypeDefinition`:
- URL placeholder name for the entity-ID segment in schema-driven route generation.
- When empty, `schemaroutes.RoutesFromSchema` emits only `GET` (list) and `POST` (create) collection routes; per-entity and relationship routes are skipped.

**`schemaroutes/schemaroutes.go`** — new package:
- `RoutesFromSchema(schema, basePath, agencyIDParam, grpcService)` generates the complete `[]types.RouteInfo` from a `types.Schema`.
- All pattern strings use `/{` + `entityIDParam` + `}` — no hardcoded `{entityId}`.
- No fallback: types without `EntityIDParam` skip per-entity and relationship routes entirely.

**`registrar/registrar.go`** — public API cleanup:
- `registrar.New` now accepts `[]types.RouteInfo` instead of `[]*crossv1.RouteDeclaration`.
- Proto conversion (`routesToProto`) is internal — proto types no longer leak into callers' code.

#### CodeValdAgency

**`schema.go`** — `EntityIDParam` set on all 11 typed entities in `DefaultAgencySchema()`:

| Type | EntityIDParam |
|---|---|
| Goal | `goalId` |
| Workflow | `workflowId` |
| WorkItem | `workItemId` |
| Instruction | `instructionId` |
| Deliverable | `deliverableId` |
| DeliverableResult | `resultId` |
| ContentRef | `contentRefId` |
| ConfiguredRole | `configuredRoleId` |
| AgencySnapshot | `snapshotId` |
| AgencyPublication | `publicationId` |
| AgencyPublicationStatus | `publicationStatusId` |

**`internal/registrar/registrar.go`** — `agencyRoutes()` now calls `schemaroutes.RoutesFromSchema` for entity/relationship routes and returns `[]types.RouteInfo`; the hand-maintained per-type route list is removed.
