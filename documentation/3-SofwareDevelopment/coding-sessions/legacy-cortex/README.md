# Legacy CodeValdCortex Session Logs

The two files in this folder were authored against **CodeValdCortex** in
October 2025 — before the CodeValdAgency service existed as a separate
repository. They were copy-pasted into this repo's `coding-sessions.md` and
preserved here verbatim so the historical record is intact, but **none of the
content describes the current CodeValdAgency code**:

- branches use the `feature/MVP-001` / `feature/MVP-015` series, not `feature/AGENCY-*`
- env vars are prefixed `CVXC_*` (Cortex), not `CODEVALDAGENCY_*` / `AGENCY_*`
- the database name is `codevaldcortex`
- features described (HTMX dashboard, Templ components, agent state cards) live in CodeValdCortex, not here

Treat these as archive material. New sessions go in the parent
[`coding-sessions/`](../) folder, dated and tagged with the relevant
`MVP-AGENCY-*` task.
